# Corp run reports

One file per corp-network validation session: `<YYYY-MM-DD>.md`.

Written by whoever (or whatever) runs the session, following
[`../CORP_AGENT_BRIEF.md`](../CORP_AGENT_BRIEF.md). The brief's §3 defines the format.

**These files are evidence, not narrative.** Counts, timings, verdicts, blockers. No message
bodies, subjects, addresses or secrets — see the brief's §2 privacy contract. Snapshots and LLM
recordings are gitignored and are handed over out-of-band; only their *shape* is recorded here.

Why the directory exists: corp sessions were run several times through mid-2026 and left no
artifact in the repo, so `docs/planning/STATUS.md` reported "never validated live" while live runs
were happening. A session that produces no file here did not happen.
